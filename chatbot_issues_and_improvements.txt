5. ABOUT PAGE HERO SECTION BROKEN MARGINS
   -------------------------------------------------------------------------
   Issue:
   - "Excellence in Every Smile" heading and subtext are off-centered
   - Margins appear broken or not in original position
   - Caused by index-s.css overriding about.css styles

   Root Cause:
   - index-s.css defines .hero-content with flexbox layout
   - .user-greeting has margin-bottom: 300px
   - These styles from index-s.css override about.css

   Fix Applied:
   - Added CSS overrides in about.css:
     .about-hero .hero-content {
         display: block !important;
         justify-content: center !important;
         align-items: center !important;
         gap: 0 !important;
         flex-direction: unset !important;
     }
     .about-hero .user-greeting {
         margin-bottom: 0 !important;
         flex: unset !important;
         min-width: unset !important;
     }

   Status: FIXED
